✂️ The Ponytail Laziness Decision Ladder (Anti-Bloat Gate)

Ascend this ladder before writing any code to prevent hallucinations and bloat:

Level 1
YAGNI (You Aren't Gonna Need It)
Does this requirement or helper function need to exist at all? If not, delete it.
Level 2
Standard Library
Does Python (pathlib, itertools, crypto) or JS/TS (fetch, URL, crypto) standard library do it natively?
Level 3
Platform / Browser Native
Is there a native HTML5 element (<dialog>, <details>) or CSS feature (:has, view transitions)?
Level 4
Existing Installed Dependency
Can an existing library in package.json or pyproject.toml solve it without adding a new package?
Level 5
Clean One-Liner
Can it be written in a single readable standard expression?
Level 6
Minimal Surgical Code
Only then write the minimum surgical implementation and write a deterministic test for it.
